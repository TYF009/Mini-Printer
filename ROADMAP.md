# Roadmap / 路线图

## Included in this integration

- English-first presentation and matching Chinese guidance.
- Android 0.2.1, regression checks and BLE exception recovery.
- Firmware framing/fault-exit hardening with explicit verification scope.
- Final supplied board source, existing exports and named enclosure STLs.
- Product film, app tour and engineering evidence with provenance.

## Next milestones

- Physically validate the hardened firmware and latest Android together when hardware testing resumes.
- Reconcile final battery/BOM/FPC specifications against actual purchased parts.
- Record assembled-device photography, slicer settings and numbered assembly steps.
- Resolve idle temperature and strengthen print completion/flow control.
- Evaluate typed Android job events and separate editor/navigation/device responsibilities.
- Evaluate signed release distribution and a current target SDK separately from this development APK.

These are planned improvements, not completed features or promised dates.
