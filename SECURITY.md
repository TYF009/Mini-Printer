# Security reporting / 安全问题反馈

This open hardware project includes a development Android build. It does not claim commercial certification, an authenticated BLE transport or a security audit.

Use GitHub private vulnerability reporting if available. Otherwise open a minimal issue requesting a private contact route; omit exploit details, device identifiers and personal data until a private route is agreed. No response-time SLA is promised.

Ordinary bugs and build failures belong in public issues. Never publish keys, tokens or unredacted personal logs.

中文：涉及隐私或可利用行为的问题，优先使用仓库可用的私密漏洞报告入口；否则先创建仅请求私下联系渠道的问题，不公开利用细节或个人设备信息。普通问题可公开反馈，本项目不承诺安全审计或企业服务 SLA。
