# 引脚分配表（ESP32-S）

以下引脚分配由嘉立创工程网表（PAD_NET）与固件 `src/em_config.h`（V4 引脚组）逐脚核对一致。

## 打印头控制

| 信号 | ESP32 引脚 | 方向 | 功能 |
|---|---|---|---|
| STB1 | IO14 | 输出 | 加热选通 1 |
| STB2 | IO27 | 输出 | 加热选通 2 |
| STB3 | IO26 | 输出 | 加热选通 3 |
| STB4 | IO25 | 输出 | 加热选通 4 |
| STB5 | IO33 | 输出 | 加热选通 5 |
| STB6 | IO32 | 输出 | 加热选通 6 |
| LAT  | IO12 | 输出 | 移位寄存器锁存 |
| DI   | IO13 | 输出 | SPI 数据（HSPI MOSI） |
| CLK  | IO15 | 输出 | SPI 时钟（HSPI CLK，1MHz MODE0） |

## 电机（TC1508S 双 H 桥）

| 信号 | ESP32 引脚 | 功能 |
|---|---|---|
| IN1 | IO23 | A 相 |
| IN2 | IO22 | A 相 |
| IN3 | IO21 | B 相 |
| IN4 | IO19 | B 相 |

## 传感器与电源控制

| 信号 | ESP32 引脚 | 功能 |
|---|---|---|
| THER | IO36（仅输入） | 打印头 NTC 温度（10k 上拉，3V3） |
| POWER_ADC | IO34（仅输入） | 电池电压分压采样（1:1，R6/R7 各 10k） |
| PHINT | IO35（仅输入） | 缺纸中断（LM393 整形输出，10k 上拉） |
| VH_EN | IO17 | 打印头电源开关（经 Q23 NMOS → Q21 PMOS） |
| BTN | IO5 | 功能按键（RC 消抖 + 软件消抖） |
| LED | IO18 | 状态指示灯（低电平点亮，1k 限流） |

## 其他

| 信号 | 连接 | 功能 |
|---|---|---|
| U0TXD / U0RXD | CH340C | 串口下载 / 调试 |
| IO0 / EN | Q1 / Q25（SS8050×2） | DTR/RTS 自动下载电路 |
| IO4 | 未连接（网表核对） | 固件中原为采样使能脚，此板悬空 |

> 注意：IO34/35/36 为仅输入引脚，无内部上拉，传感器均依赖外部上拉/分压电阻。
