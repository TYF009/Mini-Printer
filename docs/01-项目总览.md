# 01 · 项目总览

## 1. 项目背景

外出场景下打印照片、错题、单词卡等需求一直存在，但传统打印机体积大、需要外接电源，无法随身携带。本项目目标是一款**便携、易用、功能丰富的掌上打印机**：电池供电、蓝牙连接手机 App、即编即打，满足外出时打印照片、文字、学习资料的个性化需求。

## 2. 产品定义

**一句话描述**：电池供电的小型蓝牙热敏打印机——手机编辑，蓝牙发送，随时打印。

**用户使用流程**：

```
购买产品 → 下载手机 App → 蓝牙连接打印机 → 选择/编辑打印内容 → 排版预览 → 发送打印
```

**核心功能**：

| 功能 | 说明 |
|---|---|
| 打印相片 | 手机相册选图，App 内裁剪/编辑/排版后打印 |
| 打印文字 | 输入文字内容，App 排版后打印 |
| 自定义编辑 | App 提供编辑器，支持个性化排版 |
| 学习场景 | 错题整理、单词卡等学习资料的打印 |
| 电池供电 | 内置锂电池，充放电管理完善，无需外接电源 |

## 3. 需求拆解 → 技术方案映射

从"电池供电、小型、打印机、蓝牙连接"四个需求关键词出发，逐项拆解为可实现的电路/软件模块：

| 需求 | 拆解 | 本项目对应方案 |
|---|---|---|
| 电池供电 | 充放电管理 | ME4054 线性充电芯片，Type-C 5V 输入 |
| | 电压转换 | 双路架构：LDO 出 3.3V 供数字电路；升压出 VH 供打印头 |
| | 电量检测 | 电阻分压 + ESP32 ADC 采样，百分比上报 App |
| | 开关按键 | PMOS 软开关机，避免机械开关切断大电流 |
| 小型 | 紧凑设计 | 双层 PCB、打印头总成经 32Pin FPC 排线连接 |
| 打印机 | 热敏打印机芯 | 384 点/行热敏打印头（加热模块 + NTC 温度电阻 + 缺纸传感器 + 步进电机四件一体） |
| 蓝牙连接 | 主控集成蓝牙 | ESP32 片上 BLE，GATT 服务直连手机 App |

其中"打印机芯四件套"是整机的核心部件：加热模块负责成像、步进电机负责走纸、NTC 热敏电阻提供过热保护、缺纸传感器提供缺纸停机——四者对应固件中的打印驱动、电机驱动、温度检测、缺纸检测四个软件模块。

## 4. 主控选型

**选型需求**：支持蓝牙、Arduino 生态、供货稳定、外设资源丰富。

**结论**：选用乐鑫 [ESP32](https://www.espressif.com.cn/zh-hans/products/socs/esp32) 系列单芯片方案（板载 ESP32-S 模组）。

选型对比（同价位可选路线）：

| 候选方案 | 优势 | 劣势 |
|---|---|---|
| **ESP32（选用）** | BLE + WiFi 片上集成，双核 240MHz，Arduino/PlatformIO 生态成熟，资料与社区极丰富，供货稳定价格低 | ADC 精度一般（本项目用 eFuse 校准缓解） |
| STM32 + 外挂蓝牙模块 | STM32 生态成熟 | 蓝牙需外挂透传模块，两颗芯片增加成本、板面积与联调复杂度 |
| nRF52 系列 | BLE 性能最强 | Arduino 生态与中文资料相对少，开发上手慢 |

关键理由：**蓝牙是本产品的刚需，ESP32 是同时满足"片上蓝牙 + Arduino 开发 + 供货稳定"三个条件的最短路径**——单芯片完成 BLE 协议栈与打印控制，无需处理双芯片间通信。

**开发框架说明**：固件基于 Arduino 框架开发（PlatformIO 工程管理）。Arduino-ESP32 core 底层即 FreeRTOS 实时操作系统 + ESP-IDF HAL，因此项目同时具备 Arduino 的开发效率与 RTOS 的多任务能力——本项目中的打印任务、上报任务、按键任务即运行在这套 FreeRTOS 之上。

## 5. 系统总体架构

项目按"硬件设计 / 软件设计 / 项目整合"三大板块推进：

```
┌─ 硬件设计 ──────────────────────────────────────┐
│ 最小系统 · 充电管理 · 电源架构 · 电量检测        │
│ 按键 · 指示灯 · 温度检测 · 缺纸检测              │
│ 电机驱动 · 打印头接口 · PCB Layout · 焊接调试    │
└─────────────────────────────────────────────────┘
┌─ 软件设计 ──────────────────────────────────────┐
│ 任务模型(多任务) · 消息队列 · BLE 通信           │
│ 电量/温度/缺纸采集 · 按键状态机 · 步进电机       │
│ 打印驱动(SPI+STB 分时加热) · 打印任务状态机      │
└─────────────────────────────────────────────────┘
┌─ 项目整合 ──────────────────────────────────────┐
│ 多文件工程整合 · 手机 App 通信联调 · 整机调试    │
└─────────────────────────────────────────────────┘
```

**整机数据流**：手机 App 编辑排版 --BLE--> ESP32 接收入环形缓冲 --> 打印任务逐行取数 --> SPI 送数/LAT 锁存/6 路 STB 分时加热 + 步进电机走纸 --> 热敏纸成像；全程由电量、温度、缺纸三类监测保护。
