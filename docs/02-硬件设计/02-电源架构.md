# 02-硬件设计 · 02 · 电源架构（充电管理 / 稳压 / 升压）

整机电源分三路：**充电管理**（Type-C → 锂电池）、**稳压**（电池 → 3.3V 数字电源）、**升压**（电池 → 7.2V 打印头电源 VH）。

## 1. 充电管理（ME4054B-N，整机位号 U22）

**需求**：产品不接电源外出使用 → 内置一颗 2000mAh 锂电池（3.7~4.2V），充电电流 1000mA 内。

**电池选型的关键：动力电池**。普通锂电池最大放电约 1C（2000mAh 电池即 2A），而打印头峰值功率 17W+（见下文升压一节），电池放电电流远超 2A——动力电池支持 10C 放电，满足打印瞬时大电流需求。这是本产品电池选型与普通消费电子最大的不同点。

**充电芯片 ME4054B-N**（整机实配 ME4054BM5G-N）：

- 最大充电电流 500mA，封装小（SOT-23-5）
- **充电电流可通过 PROG 引脚电阻调整**：R_PROG = 1200 / I_CHG（kΩ），按实际电池规格配置
- Type-C 5V 输入，充电状态经指示灯指示（充电中亮绿灯，充满转灭/变色）

## 2. 稳压：XC6210B332MR LDO（3.3V 数字电源）

**需求**：ESP32 及外设需 3.3V、500mA 以上；电池电压 3.7~4.2V。

**为什么不用经典的 AMS1117-3.3？**

| 参数 | AMS1117-3.3 | XC6210B332MR |
|---|---|---|
| 压差 | 约 1.3V@1A | **100mV@200mA** |
| 额定电流 | 1A | 900mA |

AMS1117 压差大：电池放到 3.7V 时，3.7 − 1.3 = 2.4V，**输出根本达不到 3.3V**，电池还没用完系统就掉电了。XC6210 是低压差 LDO，电池全程电压范围内都能稳定输出 3.3V，这正是电池供电场合选 LDO 的核心指标——**看压差，不只看电流**。外围仅输入/输出各 1μF 旁路电容（详见《01-最小系统》2.2 节）。

## 3. 升压：AP2005（7.2V 打印头电源 VH）

**打印头电源需求的推导**（规格书）：一行 384 个加热点，分 6 个 STB 通道、每通道 64 点，**同一时刻只加热一个通道**（这是打印头驱动的约束，也是峰值电流可控的原因）。单点加热功率约 0.27W，则单通道最大功率：

```
P = 0.27W × 64 = 17.3W
I = P / VH = 17.3 / 7.2 ≈ 2.4A
```

所以需要一路 **7.2V、≥2.5A** 的电源。单节锂电池只有 3.7~4.2V，必须升压——选用 **AP2005**（整机位号 U23，AP2005SPER），配 4.7μH 功率电感 + SS54 肖特基，输出端 47μF×2 + 100nF×2 大容量储能，支撑加热瞬时电流。输出电压由反馈分压电阻决定（整机 R30 11k / R33 1k）。

**VH 供电必须可控开关**：打印头不打印时若常加高压，发热且浪费电量，整机板用"NMOS(Q23) ← IO17(VH_EN) → PMOS(Q21)"两级开关实现打印时按需上电（详见《01-最小系统》位号对照及 docs/architecture.md 电源树）。

## 4. 升压电路 Layout 要点（高频部分，直接影响打印效果）

升压是 DCDC 开关电路，开关节点（SW 引脚 → 电感 → 肖特基）是全板最高频的 dv/dt 节点，**布局不合理产生的纹波和噪声会耦合进打印头驱动，表现为打印条纹/深浅不均**。要点：

1. **功率环路最短**：输入电容 → 芯片 VIN/SW → 电感 → 肖特基 → 输出电容，这一圈面积越小越好
2. 输入/输出滤波电容**就近摆放**在芯片引脚旁
3. 反馈分压电阻靠近 FB 引脚，远离电感（防止磁干扰耦合进反馈，导致输出电压漂移）
4. GND 大面积铺铜 + 过孔群散热
5. **升压模块背面不走线、不摆件**（PCB Layout 章节详述）

## 5. 电源树总览

```
Type-C 5V ──> ME4054 充电 ──> 2000mAh 动力锂电池 (VBAT)
                                  │
                                  ▼ Q2 PMOS（整机软开关）
                              VBAT_OUT
                 ┌────────────────┼────────────────┐
                 ▼                ▼                 ▼
          XC6210 LDO      Q21 PMOS←VH_EN      TC1508S 电机驱动
            3.3V 数字         │ VCC_IN              │（走纸电机）
                              ▼                     │
                    AP2005 升压 → VH(7.2V) ──> 打印头加热
```
