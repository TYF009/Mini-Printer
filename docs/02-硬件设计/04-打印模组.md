# 02-硬件设计 · 04 · 打印模组（机芯 / 温度 / 缺纸 / 电机 / FPC）

## 1. 一体化机芯选型

打印模块需要加热打印、缺纸检测、温度检测、走纸电机四项能力。本项目选择**精芯一体化机芯**：打印头、步进电机、热敏电阻、缺纸传感器集成在一个机芯里，对外只引出一条 FPC 软排线——结构紧凑、装配稳定，免去逐一分立选型的联调成本。

**FPC 连接器**：1mm 间距、下接式（整机位号 FPC21，型号 X10B25L30T，30Pin，原理图符号含 2 个壳体焊盘共 32 pad；学习版选料 C500182）。按打印头信号线序，需要连接的信号分三类：

| 信号类 | 信号 | 说明 |
|---|---|---|
| 电源 | VH（多脚） | 打印加热电源 7.2V，不打印时须断电（VH_EN 控制，见电源架构） |
| 控制 | STB1~6 / LAT / CLK / DI | 通道选通 6 根 + 锁存/时钟/数据 3 根，全部接主控 IO |
| 传感 | THER / PHE（光电输出） | 热敏电阻 / 缺纸信号 |

## 2. 热敏电阻测温（打印头过热保护）

**风险**：热敏打印靠加热成像，长时间连续加热有烧毁打印头的风险，必须做温度监测。

**电路**：打印头内置 NTC 热敏电阻，TM 一端接地、另一端接 THER 网络，板上 10kΩ 电阻把 THER 上拉到 3.3V（整机 R22）。只需读 THER 端 ADC 值即可：

1. 分压公式反算 NTC 阻值：`Rt = V_adc × 10000 / (3.3 − V_adc)`
2. 由 B 值公式（B=3950 两点标定模型）或厂家 RT 表换算实际温度

不需要高精度测量（只需过热保护阈值判断），上拉用普通电阻即可；要更准可换 1% 精度。固件阈值：>65℃ 停止打印（软件实现见《03-软件设计/05-温度采集》）。

## 3. 缺纸侦测（光电传感器 + LM393 比较器）

**风险**：无纸打印会导致打印异常（加热头空烧、胶辊损伤），需要缺纸检测。

**传感器原理**：机芯内置**反射式光电通断传感器**——发光管发出红外光，有纸时被纸面反射、接收管收到光；缺纸时光无法反射、接收管收不到。比较电路整形后输出数字电平：

```
缺纸：光无反射 → 接收管截止 → 输出高电平
有纸：光被反射 → 接收管导通 → 输出低电平
```

**比较器电路**（整机 U29，LM393）：光电输出（C404321PHE）接比较器输入，VSEN 接逻辑电源，PHK 经 180Ω 限流到 GND；比较阈值由分压电阻设定。输出 PHINT 接 ESP32 IO35，**上升沿中断触发立即停止打印**（缺纸瞬间即从低变高）。

两个工程细节：

1. **DRC 警告说明**：LM393 是双通道比较器，本项目只用一个通道，另一通道未连接会在 DRC/原理图检查时报警告——不影响工作。原始设计意图是第二通道做一个"纸张距离检测"，实际未采用
2. **策略**：缺纸时禁止启动打印机加热（固件在打印启动条件里检查纸状态）

## 4. 走纸电机（两相步进 + TC1508S）

**原理**：热敏打印是逐行成像，每打完一行，电机拖动打印纸前进一个行距，循环往复完成整幅图像。

机芯电机为两相步进电机，额定电压 3.5~8.5V。驱动选型：经典方案 L293D / L298 可以驱动，但价格偏贵且器件老旧，本项目选用 **TC1508S**（整机位号 U21）替代：

- 电源电压、输出电流均满足该电机需求
- 接线极简：电机四根线直接接 OUTA/B/C/D，INA/B/C/D 接主控 IO（整机 IO23/22/21/19）
- 电源直接取 VBAT_OUT（电机电压需求与电池电压区间匹配，无需额外转换）

驱动方式为四相八拍半步序列，固件以查表方式输出（软件见《03-软件设计/07-步进电机》）。

## 5. 打印头控制信号小结

| 信号 | 方向 | 作用 |
|---|---|---|
| DI / CLK | 主控→打印头 | 串行移入 48 字节行数据（SPI 时序） |
| LAT | 主控→打印头 | 锁存移位寄存器数据到加热驱动 |
| STB1~6 | 主控→打印头 | 通道选通，同一时刻仅一路通电加热 |
| VH | 电源 | 7.2V 加热电源（VH_EN 按需开关） |
| THER | 打印头→主控 | NTC 温度模拟量 |
| PHE/PHINT | 打印头→比较器→主控 | 缺纸数字量 |

完整打印时序（SPI → LAT → STB 分时加热 → 走纸）见《03-软件设计/08-打印驱动》。
