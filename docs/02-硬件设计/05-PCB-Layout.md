# 02-硬件设计 · 05 · PCB Layout 与生产检查

原理图完成后进入 Layout。流程：**原理图检查 → 转换 PCB → 板框 → 布局 → 布线 → 铺铜 → DRC 检查 → 3D 检查 → 下单**。

## 1. 前置：原理图检查与板框

- 嘉立创 EDA 中原理图转 PCB 一键完成
- **PCB 尺寸由结构决定**：本项目结构已预留板卡空间，按结构图纸绘制板框——Layout 的第一步不是摆元件，而是把结构约束翻译成板框

## 2. 元件布局：结构约束优先

本项目结构已固定五类位置，**不打算重新设计结构就必须遵守**：

1. Type-C 口位置、打印机 FPC 排线位置、开关位置、电池端子位置、按键位置——按工程给定位置摆放
2. **螺丝孔位置不可随意更改**（与结构安装孔配合）
3. **ESP32 模组必须摆在板卡边缘**：模组底面天线区下方要掏空、不允许走线（否则天线性能劣化），放边缘便于做禁布区处理
4. **升压模块（AP2005 及其电感/肖特基/电容）背面不走线、不摆件**：这是全板干扰源，预留净空

其余元件按信号流向自由摆放。

## 3. 布线：先难后易，电源优先

1. **电源走线宽度**：打印头工作峰值功率 17~20W+，电池 → 升压 → 打印头整条电源路径（VBAT_OUT/VCC_IN/VH）必须按大电流加粗走线，这是本板区别于普通控制板的硬要求
2. **升压模块下方禁止走线**（含背面），防止高频开关节点干扰耦合
3. **所有走线必须"先过旁路电容再进芯片"**：电源线先进去耦电容焊盘、再进芯片电源脚——否则电容形同虚设，高频去耦失效
4. 布线顺序：先电源线/高难度线 → 再常规信号线 → 地线最后通过铺铜和过孔连接

## 4. 铺铜

顶、底两层整板铺 GND：连接所有地网络的同时，**改善散热（大电流路径靠铺铜扩容）并提高 EMC 性能**。

## 5. 检查与下单

1. **DRC（设计规则检查）**：未连接的网络、线宽、线距、过孔规格逐项核对，有错改错
2. **3D 视图检查**：元件干涉、焊接调试空间（特别是 FPC 座、开关、Type-C 这些有机械配合的器件）
3. 下单：按需选择 PCB 参数与 SMT 贴片参数（嘉立创平台直接下单）

> 已知 DRC 警告一条不影响功能：LM393 双通道比较器仅用一个通道（详见《04-打印模组》3 节）。

## 6. 本板 Layout 要点速查（面试向）

| 要点 | 原因 |
|---|---|
| 模组放边缘、天线区掏空禁布 | 天线性能 |
| 升压环路最短、背面净空 | 开关噪声 → 打印质量 |
| 电源路径加粗 | 17W+ 峰值功率 |
| 先过电容再进芯片 | 去耦有效性 |
| 结构件位置锁死 | 机械配合 |
| 双面铺铜 GND | 散热 + EMC |
