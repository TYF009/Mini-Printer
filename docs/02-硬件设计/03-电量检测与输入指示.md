# 02-硬件设计 · 03 · 电量检测、按键与 LED 指示

## 1. 电量检测（电阻分压 + ADC）

**需求**：电池供电产品，需要知道剩余电量（供 App 显示、低电提醒）。

**原理**：电阻分压把电池电压按比例缩小，送入 ESP32 ADC 读取——与电位器读值原理相同，区别只是分压比固定。电池电压缺电约 3.3V、满电 4.2V，按区间线性估算百分比。

**电路**（整机 R27/R29/C35）：

```
VBAT_OUT ──[R27 10k]──┬── POWER_ADC ──> ESP32 IO34 (ADC1_CH6)
                      │
                  [R29 10k]        [C35 100nF]
                      │                │
                     GND ──────────────┘（RC 滤波）
```

- 分压比 1:1（10k + 10k），采样电压 = 电池电压 × 0.5，落入 ADC 0~3.3V 量程
- C35 100nF 与上分压电阻构成 RC 滤波，滤除采样高频干扰
- **采样点取在开关后（VBAT_OUT）**：整机电源有开关电路，分压挂在开关之后的电源网络上；学习版无 MOS 开关时电池经开关直接接分压即可
- 软件侧：`V_bat = ADC 毫伏 × 2`，再 map 到 0~100%（固件实现见《03-软件设计/04-电量采集》，ADC 使用 eFuse 校准的 `analogReadMilliVolts()`）

## 2. 按键（功能测试入口）

**需求**：开发阶段需要一个输入接口做功能验证。

一颗轻触按键（整机 SW2 → IO5）：

- **短按**：运行打印测试程序（6 通道 STB 各打 5 行 0x55 测试条纹，验证打印头硬件）
- **长按**：控制走纸电机连续运转（验证电机驱动）

外围为上拉电阻 + RC 消抖（硬件消抖），固件另有 10ms 轮询软件消抖状态机，双重保险（硬件见《01-最小系统》3.x，软件见《03-软件设计/06-按键状态机》）。

## 3. LED 状态指示

**需求**：设备无屏幕，用户需要直观知道运行状态与错误。

一颗 LED（整机 IO18，低电平点亮）用四种状态编码设备状态：

| 状态 | 含义（示例） |
|---|---|
| 常亮 | 工作中 / 打印进行 |
| 慢闪 | 待机 / 蓝牙可连接 |
| 快闪 | 错误（缺纸 / 过热 / 超时） |
| 暗 | 空闲 / 低功耗 |

硬件仅 LED + 1kΩ 限流电阻，全部状态逻辑由固件 `run_led()` 编码实现（软件见《03-软件设计》）。整机板上另有电源常亮灯与充电指示灯各一颗，分别由电源和充电芯片直接驱动。
