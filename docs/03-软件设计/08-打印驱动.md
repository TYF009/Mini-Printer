# 03-软件设计 · 08 · 打印驱动（核心模块）

## 1. 初始化

- CLK/DI 初始化为 **SPI**（HSPI，1MHz，MODE0），LAT/STB1~6/VH_EN 初始化为输出
- **VH 默认拉低（关闭）**——不打印时打印头电源必须关断

## 2. 打印一行时序

打印前置条件：**不缺纸 且 温度正常**，否则拒绝进入打印模式。

```
① 打开 VH（IO17 高）
② SPI 传输本行 384bit（48 字节）
③ LAT 锁存：拉低 LAT 保持 ~1us 再拉高（锁存沿把移位寄存器数据送到加热驱动）
④ STB1~6 逐通道加热：
     同一时刻只开一路（电源带不动 384 点同时加热）
     加热时长 = 基准时间 × 密度 + 黑点补偿（见下）
     加热完断电、冷却片刻，再开下一通道
⑤ 一行完成 → 电机前进 4 步（一个行高）
⑥ 回到 ② 打下一行，直至缓冲数据打完
⑦ 打印结束：VH 立即关断 + 走纸 230 步收尾出纸
```

## 3. 加热时长控制（颜色深浅的本质）

**加热时长越长，热敏纸显色越深**——打印浓度的控制变量就是加热时间：

- 基准加热时长按密度档位缩放（BLE 命令 A5 设三档：30% / 60% / 100%）
- **动态补偿（本项目亮点）**：逐通道统计该段 8 字节的黑点数（数值求和正比于 1 的位数），黑点多的通道适度追加加热时间——同一行里"黑块"与"浅纹"需要的能量不同，统一时长要么浅处烧过头、要么深处打不实
- **安全约束：单次加热控制在 3ms 左右**，长时间持续加热会损坏打印头

## 4. 电源开关时序（打印头规格书硬性要求）

| 规则 | 说明 |
|---|---|
| 上电顺序 | **先 VDD（逻辑电源）后 VH（加热电源）** |
| 断电顺序 | **先 VH 后 VDD** |
| 空闲状态 | 不打印时 VH 必须关断 |
| 开关过程 | VH 开关切换期间，STB 必须保持非工作状态（禁止选通） |
| 结束处理 | 打印结束后 VH 应即时泄放到 0V 并保持，直到下次打印 |
| 加热信号 | 电源开关期间保证加热控制信号关闭 |

固件实现：`init_printer()` 里所有 STB 初始化为非选通电平、VH_EN 默认低；打印入口才开 VH，出口立即关；STB 只在 VH 稳定后才逐个选通。

## 5. 测试模式

短按按键触发 `testSTB()`：STB1~6 通道各打 5 行 0x55（01010101 交替点阵）测试条纹——一眼可辨每通道是否工作正常、条纹深浅是否一致，是打印头硬件排障的第一手段。
