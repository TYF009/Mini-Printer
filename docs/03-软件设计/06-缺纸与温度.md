# 03-软件设计 · 06 · 缺纸检测与打印头温度

## 1. 缺纸检测（GPIO35）

**需求**：打印开始前必须确认有纸；无纸打印会导致加热异常。

> 安全提示：调试本模块等非打印实验时不要接打印头，且烧录的代码要保持 **VH 电源关闭**——后续接上打印模组的章节代码都必须保持"不打印时 VH 关断"这条逻辑。

**实现原理**：缺纸传感器（光电反射式）输出经 LM393 比较器整形为数字电平（缺纸=高、有纸=低，见 02-硬件设计/04）。软件两种姿势：

1. **轮询模式**（学习版）：IO 初始化为输入，每隔 5s 读一次，高电平即报缺纸
2. **外部中断模式**（整机采用）：IO 配置为上升沿中断，缺纸瞬间（低→高跳变）触发中断——**中断里只置事件标志**，业务处理（停止打印、清缓冲、告警、上报）交回任务层做

中断模式响应快（毫秒级停机），轮询模式实现简单；整机两者结合：中断立即停 + 状态轮询周期性复查（兼做传感器掉线兜底）。

> 已知缺陷（known-issues #10）：中断触发后 detachInterrupt，重挂依赖最长 10s 的轮询周期，存在恢复检纸盲区。

## 2. 打印头温度（IO36 + NTC）

**需求**：打印靠加热成像，温度过高会损坏打印头，需要持续监测、超阈值停机。

**换算链**（12bit ADC，0~4095）：

```
① ADC → 电压      vol = AD/4095 × 3.3
② 电压 → NTC 阻值  分压模型: vol/3.3 = Rt/(10000+Rt)
                  Rt = (vol × 10000) / (3.3 − vol)
③ 阻值 → 温度     B 值公式: Rt = Rp·EXP(B·(1/T1 − 1/T2))
                  反解: T = 1/( ln(Rt/Rp)/B + 1/T2 ) − 273.15
                  （Rp=30k、B=3950、T2=298.15K，整机固件参数）
```

分压模型的验证：当 Rt=10k 时 vol=1.65V，即 1.65/3.3 = 10000/(10000+10000)，自洽。

**公式法 vs 查表法**：

| | 公式法 | 查表法 |
|---|---|---|
| 实现 | 每次实时计算（浮点+log） | 预生成 Rt→温度数组，查最接近项 |
| 效率 | 低 | 高（空间换时间） |
| 精度 | 受模型误差限制 | Rt 表越密越准 |

本项目用公式法（保护阈值判断不需要高精度，算力富余）。

**保护策略**：温度 > 65℃ → 停止打印 + 状态上报；打印任务启动前也会先检查温度。温度异常与缺纸共用"异常→停机→清缓冲→告警→上报"的处理框架（em_task 状态机统一调度）。

> 已知缺陷（known-issues #15）：float→uint8_t 隐式截断，极端值会回绕。
