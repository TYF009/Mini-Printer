# 来源、作者与展示素材

[English](../en/provenance.md) · [文档导航](index.md)

FOLI 基于用户提供的 Mini-Printer 资料。项目负责人声明已购买原项目相关权利；该声明不替代依赖自身的许可证，也不意味着所有继承设计均由 FOLI 独立创作。仓库区分既有平台、新实现和产品展示工作。

| 资料 | 来源与处理 |
|---|---|
| 控制板 | 用户指定最终嘉立创工程，保存为 [foli-mainboard.epro2](../../hardware/EDA-project/foli-mainboard.epro2) |
| 既有固件 | Mini-Printer 源码与仓库历史；加固修改应对应提交与验证范围 |
| 机械设计 | 用户提供的 230918 装配体和日期命名 STL；英文重命名不代表重新设计几何 |
| FOLI Android | 为本产品体验制作的原生 Java App；通过阅读既有协议建立互通 |
| Android 依赖 | AndroidX ExifInterface 与构建工具，见[第三方说明](../../software/android/THIRD_PARTY_NOTICES.md) |
| 历史照片 | 用户提供的测试台与热敏测试页，不是全部新组件的复测 |

原教学资料关联小智学长 Mini-Printer 项目，其说明与示例提供背景；最终配置应以选定电路文件和代码为准。工作资料中的 ESP32-S3 AI terminal 等无关工程不属于 FOLI。

## 媒体类型

- 主视觉与生活场景：依据实际 CAD 参考生成的 AI 概念图，可能存在细微结构或材质差异。
- CAD 镜头：导入已有装配体后添加材质、灯光与示意展开。
- 出纸：贴有文字的三维纸面示意，不证明打印速度。
- App GIF：真机截图与运动重建；当前 Device 页根据源码重绘为离线状态，不是实际操作录屏或 FPS 证据。
- 系统图：由光栅／协议源码支持的概念链路，不是实时遥测。
- 硬件证据图：历史照片旋转排版，保留原测试内容。
- 声音：原创程序编排与合成拟音，无第三方配乐／采样包，不称为现场录音。

[产品视频](../../media/video/FOLI-Made-Tangible-90s.mp4)拆分使用时仍应保留准确来源说明。原制作使用系统 Segoe UI 与 Georgia，字体文件不随项目分发。脚本与生成提示词应随制作源资料保存；能观看成片不代表安装了全部可选制作依赖。

## 品牌与复用

FOLI 和 “Little prints. Everyday joy.” 为选定项目身份。暖白、薄荷等配色是设计提案，不代表所有配色均已生产。名字未完成商业清查，初步资料发现另一个 Foli 品牌 App；不承诺商标、商店名称或域名可用。

复用前查看仓库许可证与保留的第三方说明。硬件、机械、生成媒体与软件展示在同一 README 中，不意味着其上游条款完全一致。保留来源，不把概念渲染称为实拍，也不把历史测试称为新版全部验证。
