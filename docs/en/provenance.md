# Sources, authorship and presentation media

[简体中文](../zh-CN/provenance.md) · [Documentation](index.md)

FOLI builds on Mini-Printer hardware and mechanical materials supplied under the owner's purchased project rights. Source credits and dependency notices are retained. This documentation identifies the platform, new Android implementation, integration changes and presentation work.

## Engineering materials

| Material | Origin and handling |
|---|---|
| Mainboard | Owner-selected final JLCEDA project, retained as [foli-mainboard.epro2](../../hardware/EDA-project/foli-mainboard.epro2) |
| Legacy firmware | Mini-Printer code and existing repository history; hardening changes must be identified by commit and verification scope |
| Mechanical design | Supplied 230918 assembly and dated STL parts; English filenames do not imply new geometry authorship |
| FOLI Android | Native Java app created for this product experience; legacy protocol inspected for interoperability |
| Android dependencies | AndroidX ExifInterface and build tooling; see [third-party notices](../../software/android/THIRD_PARTY_NOTICES.md) |
| Historical photographs | Supplied hardware bench and thermal test-page photographs; not new tests of the complete updated stack |

The original teaching materials are associated with 小智学长's Mini-Printer project. Their narrative and examples are background sources; final board files and selected code determine the implemented configuration. Unrelated ESP32-S3 AI-terminal materials in the working collection are not part of FOLI.

## Media register

| Media | What it depicts |
|---|---|
| Hero/lifestyle scenes | AI-generated concept images referencing the actual CAD; possible small geometry/material differences |
| CAD product/assembly motion | Imported supplied assembly with visualization materials and illustrative separation |
| Paper-feed animation | Textured CG paper illustration; no measured printing-speed claim |

| Evidence sheet | Historical photos, rotated for readable presentation; original test content retained |
| Music and action sounds | Original procedural composition and synthesized Foley; no external music/sample pack or field-recording claim |

The product film is [available here](../../media/video/FOLI-Made-Tangible-90s.mp4). Presentation labels should remain accurate when reusing individual clips outside the full film. Reconstructed UI animation is not evidence of device FPS.

System fonts used during original production include Segoe UI and Georgia; font files are not redistributed. Media source scripts and generation prompts should be retained with the production assets. A rendered file being easy to view does not guarantee that every optional media-generation dependency is installed.

## Identity

FOLI and “Little prints. Everyday joy.” are the selected project identity. Chalk/Mint and other color studies describe visual proposals, not independently manufactured product variants.

## Reuse

Consult the repository license and retained dependency notices for the material you intend to reuse. Hardware, mechanical inputs, generated media and software should not be assumed to have identical upstream terms solely because they are displayed on one README. Preserve source attribution and do not describe concept renders as photographs or historical testing as qualification of a newer release.
