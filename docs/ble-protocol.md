# BLE 应用层协议

## 传输载体

- 角色：ESP32 为 BLE Server（从机），手机 App 为 Client
- Service UUID：`4fafc201-1fb5-459e-8fcc-c5c9c331914b`
- Characteristic UUID：`beb5483e-36e1-4688-b7f5-ea07361b26a8`
- 特征权限：Read / Write / Write Without Response / Notify（挂 BLE2902 描述符）
- MTU 注意：单包打印数据 ≤ 20 字节（默认 MTU 23）时 App 需分包；固件按行（48 字节）组包

## 下行（手机 → 设备）

### 打印数据包

任意非命令前缀的字节流，按序写入打印缓冲，每满 48 字节构成一行（384 点）。

### 命令包（固定 5 字节）

| 命令 | 格式 | 说明 |
|---|---|---|
| 设置打印密度 | `A5 A5 A5 A5 xx` | xx=1 → 30%，xx=2 → 60%，其他 → 100% |
| 数据发送结束 | `A6 A6 A6 A6 xx` | xx 任意；设备置位接收完成标志，满足条件后开始打印 |

> 已知缺陷：固件对 A6 包处理后未 return，该包会作为打印数据入队（见 known-issues.md #2）。

## 上行（设备 → 手机，Notify）

设备状态包（4 字节，每 10s 周期或事件触发）：

| 字节 | 内容 |
|---|---|
| 0 | 电量百分比（0~100） |
| 1 | 打印头温度（℃，uint8） |
| 2 | 纸状态（有纸/缺纸） |
| 3 | 打印状态机状态 |

事件触发上报：打印开始（START）、缺纸、过热、打印超时。

## 打印启动条件

`START_PRINTER_WHEN_FINISH_RAED = 1`（当前配置）：收到 A6 结束包后才开始打印；置 0 时缓冲攒够 100 行即边收边打（流式模式）。
